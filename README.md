# EQUINOX: Heaven vs Hell

A self-contained browser-playable prototype. No build tools or external libraries are required.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your repository.
2. In GitHub, open Settings → Pages.
3. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Wait for the Pages deployment in the Actions tab to finish.

## Prototype contents
- Aether and Umbra faction selection
- 20-card faction decks
- 4000 Life Points and five-card opening hands
- Five monster zones per player
- Normal summons and tribute requirements
- Attack/defence position changes
- Monster combat, spell effects, CPU turn, deck-out and victory checks

This is an early playable prototype, not a finished competitive card game. Mobile browser testing and deeper rules balancing are still required.
