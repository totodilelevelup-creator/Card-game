# Testing checklist

- [ ] Open index.html in Chrome or Firefox
- [ ] Choose Aether and start a duel
- [ ] Confirm five cards appear in the hand
- [ ] Select a monster and Normal Summon
- [ ] Select a monster zone and change position
- [ ] Attack an opposing monster or attack directly
- [ ] Activate a spell card
- [ ] End turn and confirm the CPU takes its turn
- [ ] Confirm LP reaching zero ends the duel
- [ ] Check layout on a narrow mobile screen
